# P018 offline evidence checker (partial implementation)

`scripts/p018_watch_trial_evidence.py PATH` checks one explicitly supplied local JSON file. It does not access a network, activate Bluetooth, authenticate a source, compare host and Watch files, or qualify hardware. Input is limited to 128 KiB and 64 events. Duplicate keys and unknown fields are rejected. Errors do not echo input or paths. The output always includes `physical_qualification: not_qualified` and `authorization: never_evaluated`.

Version 1 is an operator-prepared envelope; it is **not** the existing P007B or host diagnostic export, nor a signed device attestation. It has exactly these fields: `schema_version` (integer 1), `trial_id` (32 lowercase hexadecimal characters, locally generated and never transmitted over BLE), `stage` (W0 through W6), `source` (`mock_ci`, `host_runtime_observed`, `watch_runtime_observed`, `operator_declared`, or `independent_observer`), `result` (`pass`, `fail`, `blocked`, or `not_run`), `authorization` (`never_evaluated`), and `events` (array).

Each event has exactly `sequence` (zero-based contiguous integer), `elapsed_ms` (nondecreasing integer, at most 3,600,000), `phase` (`start`, `registration`, `discovery`, `transport`, `decision`, `cleanup`, `terminal` in that order), and `outcome` (`attempted`, `confirmed`, `failed`, `cancelled`, `expired`, `unknown`, or `complete`). Nonempty traces start with attempted start, end in terminal, and contain cleanup. A claimed pass needs confirmed cleanup, a complete terminal and the stage-specific phase for W1–W6. Claimed pass or failure needs events. A confirmed cleanup is still only a claim and is not proof of independent RF cessation.

Do not include addresses, names, D-Bus paths, raw packets, payloads, signatures, enrollment material, identifiers or exception text. The fixed fields do not accept free text. Never use a trial ID as an endpoint identity. This format does not yet correlate multiple side-specific records or establish physical qualification; further P018 work is required.
